# Contributing

Use Node.js 22 or newer, run `npm ci`, then `npm test` and `npm run build`. Keep geometry algorithms independent of Three.js and browser APIs. Add analytic or adversarial fixtures for parser and geometry changes.

Use synthetic meshes or files with explicit redistribution rights. Do not commit scans, personal data, credentials, node_modules or generated production bundles. Document any format subset and reject unsupported input clearly rather than returning plausible but wrong measurements.

For interface changes, inspect desktop and mobile sizes in a real browser and check keyboard operation. For new measurements, explain the mathematical assumptions and when the value must be withheld. Do not add clinical/manufacturing claims or fabricated performance metrics.
